# 30世代実験(gpt-5.6-luna版) チェックポイント検証レポート

`experiment_results/lattice_fork_minmax_30gen/run_20260927_082603/`(30/30世代完走)
について、初期個体および世代10・15・20・27時点の最良個体を、それぞれ
ランダムなゴール(`goal_x_range=[15.0,16.5]`/`goal_y_range=[1.5,2.3]`)で**10回
再評価**し、統計的に検証した。手法は
[gpt-4o-mini版のチェックポイント検証](lattice_fork_minmax_30gen_checkpoint_verification_report.md)と同一。

## 対象個体

初期基準個体(`ind_000001`)は既存の自動検証データ(GP実行直後の
`--verify-repetitions 10`)を再利用し、再評価は行っていない。

**世代5は検証対象から除外した**: この実行では世代0〜5の間、その世代の
評価プールで成功した個体が1体もなく(
[gpt-5.6-luna版レポート](lattice_fork_minmax_30gen_gpt56luna_experiment_report.md#世代0初期個体が一時的に全滅した件について)参照)、
「世代5時点の最良個体」を定義できないため。

| チェックポイント | 個体 | 生成方法 |
|---|---|---|
| 初期(世代0) | `ind_000001` | initial(無変更) |
| 世代5 | (該当なし: 成功個体0体) | - |
| 世代10 | `mig_000091`(=`ind_000082`と同一コード) | migration_copy |
| 世代15 | `ind_000111` | crossover_and_mutation |
| 世代20 | `mig_000172`(=`ind_000168`と同一コード) | migration_copy |
| 世代27 | `ind_000226` | mutation_only |

## 結果(初期個体との比較、各10回、全個体10/10成功)

| 指標 | 初期個体平均 | gen10(`mig_000091`) | gen15(`ind_000111`) | gen20(`mig_000172`) | gen27(`ind_000226`) |
|---|---:|---:|---:|---:|---:|
| ノード展開数 | 42,502.7 | 30,702.9(**+27.8%改善**、p<0.0001 有意) | 18,666.0(**+56.1%改善**、p<0.0001 有意) | 14,087.1(**+66.9%改善**、p<0.0001 有意) | 8,708.3(**+79.5%改善**、p<0.0001 有意) |
| 経路長 | 38.978 m | 40.259 m(**-3.3%悪化**、p=0.0004 有意) | 40.610 m(**-4.2%悪化**、p<0.0001 有意) | 37.992 m(+2.5%改善、p=0.0003 有意) | 37.848 m(+2.9%改善、p=0.0005 有意) |
| 到達時間 | 172.558秒 | 175.832秒(**-1.9%悪化**、p=0.0162 有意) | 180.127秒(**-4.4%悪化**、p=0.0015 有意) | 172.217秒(+0.2%、p=0.737 非有意) | 172.616秒(-0.03%、p=0.968 非有意) |

(経路生成時間は外れ値の影響が大きく参考にならないため省略。詳細は
`analysis/repeat10_logs/repeat10_significance.csv`相当の生ログを参照)

## 世代を追った傾向

1. **ノード展開数は世代が進むにつれて単調に改善**し、常に統計的に有意
   (p<0.0001)。gpt-4o-mini版と同様、探索効率の改善は一貫して頑健。
2. **世代10・15では経路長・到達時間が両方とも統計的に有意に悪化**している。
   これはgpt-4o-mini版のチェックポイント検証で見られた
   「ヒューリスティックを弱めて探索を広げ、その分ノード展開数は増えるが
   経路の質は上がる」という前半の傾向とは異なり、**今回は経路の質まで
   悪化させながらノード展開数だけを改善する**方向に進んでいた。
3. **世代20以降で経路長が改善に転じ(有意)、到達時間も悪化ではなく
   ほぼ横ばい(非有意)に回復**している。最終的な世代27時点の個体は、
   ノード展開数を79.5%改善しつつ、経路長も2.9%有意に改善、到達時間は
   悪化も改善もしていない(統計的に区別不能)という、4指標中3指標で
   問題のない結果に落ち着いている。

## gpt-4o-mini版との比較

| | gpt-4o-mini版(世代27時点) | gpt-5.6-luna版(世代27時点) |
|---|---|---|
| ノード展開数 | +51.9%改善(有意) | **+79.5%改善(有意)** |
| 経路長 | +0.9%(非有意) | **+2.9%改善(有意)** |
| 到達時間 | **-12.4%悪化(有意)** | -0.03%(非有意) |

**最も重要な違い**: gpt-4o-mini版は世代27時点の最良個体でも到達時間が
統計的に有意に悪化していた(過学習が最後まで残っていた)のに対し、
**gpt-5.6-luna版は世代20〜27にかけて到達時間の悪化が解消され、最終的には
有意差なし(≒同等)まで回復している**。経路長も有意に改善しており、
gpt-5.6-luna版の方が最終的な頑健性の面で優れた結果になった。

ただし、両実験とも**世代10〜15付近では経路長・到達時間の悪化が実際に
起きていた**(gpt-5.6-luna版は今回の検証で新たに判明、gpt-4o-mini版は
既に判明済み)。この中間段階だけを見て「改善した」と判断するのは
どちらの実験でも危険であり、複数世代・複数ゴール群での検証が引き続き
重要であることが改めて確認された。
